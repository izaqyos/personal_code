# Matplotlib Practice - Quick Start

## 🚀 Two Ways to Run

### Method 1: Wrapper Script (No activation needed!)
```bash
./run.sh --list              # List exercises
./run.sh 1                   # Run exercise 1
./run.sh 1 --interactive     # Interactive mode
```

### Method 2: Activate Environment
```bash
source activate.sh           # Activate venv
python run_exercises.py 1    # Run exercise 1
python ex01_basic_line_plots.py  # Run file directly
```

## 📚 Exercises

1. **Basic Line Plots** - `./run.sh 1`
2. **Subplots & Layouts** - `./run.sh 2`
3. **Bar & Scatter** - `./run.sh 3`
4. **Histograms** - `./run.sh 4`
5. **Styling** - `./run.sh 5`
6. **Annotations** - `./run.sh 6`
7. **Advanced (3D, heatmaps)** - `./run.sh 7`

## 🔧 Workflow

1. Open exercise file (e.g., `ex01_basic_line_plots.py`)
2. Find the TODO comments
3. Replace `pass` with your matplotlib code
4. Run: `./run.sh 1`
5. View plots, iterate!

## 💡 Tips

- Close plot windows to proceed to next exercise
- Use `--interactive` to pause between plots
- Sample data is provided in each file
- Add notes in the "NOTES & INSIGHTS" section

Happy plotting! 📊
