## Learning Path

### Phase 1: Classic ML Foundations
Build mathematical intuition and understand core algorithms:
- Fundamentals (bias-variance, overfitting, cross-validation)
- Linear & Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machines (SVM)
- Decision Trees & Random Forests
- Gradient Descent optimization
- Loss functions and evaluation metrics

### Phase 2: Neural Networks
Understand deep learning building blocks:
- Perceptrons and multi-layer networks
- Backpropagation algorithm
- Activation functions
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs/LSTMs)

### Phase 3: Transformers & LLMs
Master modern NLP architecture:
- Tokenization strategies
- Word embeddings and positional encoding
- Self-attention mechanism
- Multi-head attention
- Transformer architecture (encoder/decoder)
- Residual connections and layer normalization
- LLM-specific layers and training

### Phase 4: Advanced Models
Explore cutting-edge research:
- VJEPA and joint embedding architectures
- Multimodal models (vision-language)
- Diffusion models
- Emerging architectures

### Phase 5: Tools & Libraries
Master development tools and essential libraries:
- Cursor IDE efficiency guide
- Claude Code CLI guide
- Python ML libraries (NumPy, Pandas, PyTorch, scikit-learn, etc.)
