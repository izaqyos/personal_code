## Study Tips

1. **Code everything** - Don't just read, implement
2. **Use Jupyter notebooks** - Interactive exploration
3. **Visualize** - Plot data, losses, predictions
4. **Start small** - Tiny datasets, simple models first
5. **Debug systematically** - Check shapes, gradients, losses
