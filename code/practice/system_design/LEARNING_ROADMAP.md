## Study Tips

1. **Time yourself** - Practice 45-min design sessions
2. **Draw diagrams** - Visual thinking is essential
3. **Estimate scale** - Always calculate QPS, storage, bandwidth
4. **Discuss tradeoffs** - No perfect solution exists
5. **Review solutions** - Learn from reference designs
