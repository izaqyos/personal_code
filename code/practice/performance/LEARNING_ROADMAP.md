## Key Reference Numbers

Memorize these for quick estimation:

| Resource | Value |
|----------|-------|
| L1 cache | 1 ns |
| L2 cache | 4 ns |
| Main memory | 100 ns |
| SSD random read | 16 μs |
| SSD sequential (1MB) | 250 μs |
| HDD seek | 4 ms |
| Network RTT (same DC) | 0.5 ms |
| Network RTT (cross-US) | 40 ms |

## Study Tips

1. **Show your work** - Break down each calculation
2. **Use powers of 10** - Simplify arithmetic
3. **Sanity check** - Is the answer reasonable?
4. **Know the bottleneck** - CPU, memory, disk, or network?
5. **Practice estimation** - Round numbers for speed
