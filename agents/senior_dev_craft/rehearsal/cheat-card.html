NFR lenses: ask → basic (critical if a requirement drives it)

Securityuntrusted input? → validate at boundary, param. queries, no secrets/PII in logs (crit: authz per resource, safe deserialization)
Resiliencedep slow/down? → timeout everywhere, retry transient+idempotent only, full jitter, deadline (crit: breaker, idempotency key, fallback)
Perf/latencybudget? n? → right complexity, no N+1, stream (crit: bounded fan-out, measure, cache+TTL)
Scalability10× breaks what? → stateless, capped pages, bounded queues (crit: partition, async workers)
Rate limitswhose quota? → honor Retry-After, semaphore (crit: token bucket per key, 429 contract)
Observability3am? → module loggers, structured fields, error once w/ traceback (crit: request id, RED, traces)
Extensibilitywhat changes? → DI via ctor, config over code (crit: Protocol seams, versioned events)
LLM in codeoutput untrusted → parse+validate+fallback, token/latency limits, eval set, cheap-first routing

Expert moves with the model

  1. Context first: task + constraints + files + standards. Prompt = spec.
  2. Plan before code; ask for 2 options + trade-offs, I decide.
  3. Trace one example by hand before designing.
  4. Tests = the oracle / eval set; green gates, not "done".
  5. Read every line; one "why" per non-obvious choice.
  6. Catch: invented APIs · dead guards · swallowed errors · hollow tests · over-abstraction · docs that lie.
  7. Take the keyboard for 2-line fixes or after 2 identical failures.
  8. Critic persona second pass; verify each claim by running.
  9. Proportionate: build the budget, name the rest.

Lines to say

  • "Constraints up front: models follow specs far better than they guess them."
  • "Two designs first: I want the trade-off before it commits."
  • "Tests first so I have an oracle; the model's confidence isn't one."
  • "That API doesn't exist in this version: checking the real signature."
  • "Different persona for review: different framing, different failures."
  • "Not building a breaker at this scope; it's the next step if outages last minutes."
  • "Its output is untrusted input: parse, validate, fall back."

Red flags to spot (Python / TS)

time.time() for durations · naive datetime · mutable default · except: pass · blocking call in async def · unbounded gather
req.body as T · floating promise · forEach(async) · no AbortSignal.timeout · catch → 200 · sync I/O in handler
no timeout · while True retry · retrying 4xx · unbounded queue/page · secrets/PII in logs · string-built SQL

Recovery

Off track → "Stop. Back to the plan, step 2 only." · Red test → read, hypothesize, fix (no random patches) · Late → most important NFR test, then the not-built list · Their tool → paste adapters/PROMPT.md.
